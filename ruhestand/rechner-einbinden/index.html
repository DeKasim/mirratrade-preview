Rechner einbinden: Der Entnahmeplan-Rechner für Ihre Seite

Betreiben Sie einen Blog, ein Forum oder eine Beratungsseite zum Thema Ruhestand? Mit einem iframe zeigen Sie unseren kompakten Rechner auf Ihrer Seite. Besucher rechnen mit eigenen Zahlen; das Widget verweist auf die vollständige Version zurück.

Was das Widget kann

  • Zeigt, bis zu welchem Alter das Kapital neben der Rente reicht – als kompakte Fassung des Entnahmeplan-Rechners.
  • Die Rechnung läuft im Browser des Besuchers. Eingaben werden nicht übertragen.
  • Verweist über einen Link auf die vollständige Version mit allen Einstellungen.

Vorschau

Die Vorschau lädt erst beim Hinscrollen. Sie zeigt das Widget so, wie es bei Ihnen aussieht.

Code zum Kopieren

<iframe src="https://mirratrade.com/embed/rechner/"
        title="Entnahmeplan-Rechner von MirraTrade"
        width="100%" height="640" loading="lazy"
        style="border:0;max-width:720px"></iframe>

Fügen Sie den Code an der Stelle ein, an der der Rechner erscheinen soll. Höhe und Breite dürfen Sie anpassen; unter 560 Pixel Höhe werden Ergebnisse abgeschnitten. [Platzhalter: Mindesthöhe nach Widget-Test festlegen]
